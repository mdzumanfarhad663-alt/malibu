# Malibu Resort Motel: design direction

## References studied

- [The Saguaro Palm Springs](https://thesaguaro.com/palm-springs/) — bold color, large imagery, prominent booking interface and direct-booking message. Malibu uses its own palette, photos, and Coastal Rewards terms.
- [Hotel Zed](https://www.hotelzed.com/) — short, lively headings and scannable amenity presentation. Malibu's copy stays grounded in the supplied property facts.
- [The Dive Motel](https://thedivemotel.com/) — a small number of large motel, bar, and pool feature blocks, each with one direct action.

These are inspiration for pacing and quality. No reference assets, text, or exact layouts are copied.

## Current wireframe

Unobscured pool photo → title and booking bar → pool → Crusty Pelican → one horizontal six-room strip → little extras → beach location → Coastal Rewards → footer.

Every page opens with a background photo and a centered white title over it. A restrained gradient behind the title improves contrast while keeping the image visible. The homepage uses a sunshine-yellow title accent, and the pool and Crusty Pelican sections use soft coral and yellow backgrounds for a livelier feel. Motion is limited to component entrance, image zoom, and button lift, with reduced-motion support.
